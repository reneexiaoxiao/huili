# 从会议到行动

## 输入与读取

先确定会议/录音标识、账号与授权范围；用来源工具读取完整逐字稿。飞书可用官方 CLI 的 `minutes +detail --transcript --as user`；精确参数以本机帮助为准，不能把会议 ID、妙记 token 和文档 token 互换。逐字稿进入本人私有工作目录，不能进入公开示例。

摘要可作定位线索，但不能替代完整发言。生成中、无权限、网络失败分别标记原因，保持 `pending_transcript`，不在事实缺口上继续生成确定结论。

## 同场去重

先按来源稳定 ID 去重，再比较候选录制时间、关联会议、时长与全文指纹。近似录音只有在内容高度重合且时段一致时合并；同名、同会议室、同一主题或时间接近不能单独判重。覆盖不一致时保留来源关系与不确定性；选择完整来源作为主记录，保留其他来源指向主记录的映射。

## 输出

使用 [默认纪要](../templates/minutes.md)：上下文、明确决定、未定问题、行动、来源。仅摘取有证据的事实。明确区分：

- 本人需要判断或执行的事项；
- 用户已授权 Agent 可直接做的工作；
- 尚需本人确认的提案。

不根据职位、发言次数或谁提到一个问题就推断责任。缺少负责人、日期或授权就保留未定。历史决定已被新发言推翻时，保留更正关系。

## 推进与完成

稳定 `actionId` 贯穿确认、领取、执行、结果；`clientRequestId` 防止重复点击和重试创建新行动。领取使用租约，失败先回读现状，过期租约不能让两个执行者同时工作。

只有真实产物生成并回读内容、权限和链接后，才能标记 `done`。需要本人补充时保持 `awaiting_confirmation`；完成背景整理不等于业务事项已完成。发送消息、改权限、发布或改业务数据都需要匹配当前动作的本人授权。
