# 个人会里的视觉定制

这是一项可选的 Agent 接手能力，不要求使用者填写设计问卷。`client/` 提供默认的纸感、宋体标题、朱红重点和已有交互。若使用者已有工作台，先在授权范围内观察并延续它的视觉与交互；若从会里开始且没有明确偏好，直接沿用默认设计。使用者给出参考页面或清楚的审美要求时，Agent 可以在本人目录里调整。

## 先确认什么

- 本人明确给出的参考或要求优先。确认是想调整整个应用，还是只调整首屏、纪要或某个工作流；参考图不自动授予复用其中素材的权利。
- 已有工作台时，确认希望把会里放到哪个入口，并核对现有导航、组件、信息密度与样式规范；必须有该工作台的读取与修改授权。先展示拟改动的一个页面和回退方式，不能承诺自动融合任意技术栈。
- 只问会影响设计决定的缺口，例如“更想要一眼看完的紧凑版，还是留白多一些的阅读版？”使用者可跳过。
- 近期会议和工作资料可帮助决定信息优先级，不能推断“这个人喜欢蓝色/极简风”。接手记录中的视觉选择标明“本人确认”或“默认值”，不要标为来源推断。

## 可以怎样改

Agent 可调整字体层级、阅读密度、色彩、导航、会议与行动的布局，以及必要的动效。先保留原应用中能认出的标题节奏和信息层级，再按明确偏好改动。首屏要让使用者看见真实业务对象、状态、时间和下一步动作；不要用通用设置表单、空白大屏或整齐卡片墙代替工作内容。颜色和装饰应帮助阅读，不应成为“已个性化”的唯一证据。

视觉定制不能改变行动确认、资料来源、账号隔离和状态回读等契约；空、加载、错误、无权限与窄屏也需要可读。先展示一个代表页面，请使用者指出不顺手之处，再扩展到其他页面。仅有样式草稿而未在本人环境运行，按 [验收](acceptance.md) 报告为预览，不能称作已完成的个人会里。
