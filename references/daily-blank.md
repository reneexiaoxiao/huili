# 今日留白：开放的作品空间

目标是给使用者一个值得停留、会心一笑或重新思考的作品。可以从工作背景获得启发，也可以留白。不要求每件作品总结会议、提高效率或给出管理建议。

## 创作步骤

1. **探索。** 在已授权的最小背景上寻找实质不同的角度。真实业务事实与创作联想分开；无素材就安静留白。
2. **取舍。** 选择一个值得完成的方向，定义声音、媒介和关键表达。避免把开放创作收缩成固定模板库或连续卡片墙。
3. **成稿。** 完成一件作品；文字、图像或受约束的 HTML 都可。需要图像时使用宿主真实生成能力，只传抽象意图，不传原文、人名、私有链接或业务数字。
4. **检查。** 作品符合来源边界、可读、可访问，并与近期作品有实质差别。没有图像能力就选择能实际完成的媒介，不造路径。

## 渲染与操作

前端有文本、组合元素、图像和 sandboxed HTML 的契约。自由 HTML 必须由服务端净化并加 CSP；iframe 不给脚本、同源、弹窗或顶层导航权限，禁止外部资源、表单和主动网络访问。保留无 HTML 的回退。

“收好”“丢弃”“丢弃并再来”“撤销”是不同状态。失败保留原作品，新作品通过验证后再替换；反馈不能解释成对人格或心理状态的判断。逐渐记住本人明确选择的表达偏好，不复制作者画像。
