# 接入验收

按实际交付范围验证；不把所有功能都作为首次预览的前提。

## 一场会议的最小闭环

- [ ] 当前本人账号与目标工作空间已核对；权限不足时不会换他人账号。
- [ ] 完整逐字稿可读；不可读时如实保留原因。
- [ ] 同一录音重试与平行录音不会无条件创建重复主记录。
- [ ] 决定、负责人、截止日期有来源；未知内容保持未知。
- [ ] 本人明确确认一项工作后，Agent 接手同一行动。
- [ ] 真实产物的内容、链接与访问权限已回读；业务状态与产物一致。

## 扩展范围

- [ ] 随手记：保存失败重试不重复，刷新能找回，完成/撤销/交接不串用户。
- [ ] 项目：完整盘点范围有记录，待归类可见，来源失效与提取失败降级责任。
- [ ] 交接：宿主持久任务可回复，重试回到同一任务；背景整理完成不标业务完成。
- [ ] 留白：缺能力与错误有真实状态，丢弃可撤销，HTML 无脚本与外部资源。
- [ ] 前端：正常、空、加载、错误、无权限、长文本与窄屏按受影响范围验证。
- [ ] 后台（若启用）：唯一事件消费者，断线/重启恢复，队列幂等和失败退避。
- [ ] 跨用户（若启用）：服务端校验每一条对象归属；前端筛选不能替代权限隔离。

回执分别列出：源码检查、示例测试、本人真实数据、另一位用户、后台运行。未做的保持未验证。
