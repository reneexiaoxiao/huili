# 能力与发布边界 · v0.2.0

本次版本调整使用许可与说明；下列产品能力沿用 v0.1.0，实际接入仍由使用者的 Agent 完成。[个人与内部使用许可](LICENSE-FAQ.md)

截至 2026-09-15，此包按“带前端的重型 Skill”发布。原产品已演进到项目责任与随手记交接；公开副本交付的是可复用代码和协议。原环境的运行记录不构成对方环境已接通的证据。

| 能力 | 公开包交付 | 仍需使用者 Agent 完成 |
| --- | --- | --- |
| 日历与会议详情 | 原前端、排序与聚合逻辑、字段契约 | 本人日历和会议适配、账号隔离 |
| 完整逐字稿与同场去重 | 工作协议、纪要模板 | 来源读取、指纹/关联实现、真实重复录音验证 |
| 会前准备与会后行动 | 界面、状态契约、接手提示 | 模型推理、行动队列、授权、产物写入与回读 |
| 系列会议、漫游与记忆 | 原前端与通用组织逻辑 | 来源完整性、关联判断与纠错 |
| 项目责任与优先级 | 原项目界面、排序与过期降级逻辑 | 项目盘点、来源提取、汇总保存与增量更新 |
| 随手记与完成撤销 | 原交互、请求标识、草稿保护；示例可在页面内操作 | 后端持久化、并发保护、跨刷新回读 |
| 随手记交接 | 通用 Agent 文案与结果链接、交接协议 | 宿主持久任务创建、背景检索、回复接续与防重 |
| 今日留白 | 原作品展示、收好/丢弃/重来状态与创作协议 | 可选生成能力、服务端校验、私有素材存储 |
| MCP / JSON CLI | 六个按需工具；标准库 Python 实现 | 用户自己的接口、飞书授权及目标宿主实测 |
| 后台与跨用户 | 架构约束与验收表 | 定时/事件机制、部署、断线恢复、数据隔离验收 |

## 明确未交付

完整的独立认证/数据库后端、预连接服务、个人邀请、桌面安装器、各宿主全链路兼容认证、多人 SaaS、自动启动的常驻进程。运行示例不需要账号，使用真实资料则必须完成相应适配。

## 连接器的范围

`huili_status`、`huili_context`、`huili_feishu_read`、`huili_sync_meeting`、`huili_claim_actions`、`huili_report_action`。它不生成图像、不自动创建宿主任务，也不自动完成项目汇总或后台监听。

连接器测试验证协议与防护行为；对特定 Agent 的导入、真实登录、数据隔离与执行能力仍需在那个 Agent 中验证。

## 首次生成接手协议（2026-09-23 待发布）

本次补充了 [首次生成个人会里](../references/first-run.md)：Agent 先问使用者是否已有常用工作台。已有且授权读取/修改时，以该工作台的结构和风格为基底融入所需界面；没有时以会里原前端为起点。Agent 再以本人已授权的少量资料为主要线索，用三个轻问题补缺，愿意的使用者可继续深入采访。这里交付的是 Agent 指令和验收约定，尚无自动生成、自动兼容任意工作台或部署服务，也未完成另一位使用者的端到端接入。此节不属于已发布的 v0.2.0 能力。
