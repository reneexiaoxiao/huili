# 让自己的 Agent 接手

这是需要适配的源码与 Skill 包。第一次使用可以从“只借鉴前端”“接入会议闭环”“扩展完整工作台”选出当前最小范围。

适配默认限于个人或组织内部自用，允许修改。对外分享原版或修改版、售卖、托管或包装推广须另行书面授权，不能把“部署”理解为公开分发。使用前阅读 [许可说明](LICENSE-FAQ.md)。

## 先交付一页接入判断

Agent 先确认以下事实，已知的不要重复询问：

| 项目 | 需要确认的事实 |
| --- | --- |
| Agent 能力 | 可读本地文件、执行命令、调用已授权资料；能否创建可回复的持久任务、生成图像与持续调度分别核验 |
| 资料 | 本人要纳入哪些日历、会议、文档、聊天与任务；优先指定的一场会议和相关资料 |
| 身份 | 当前账号、租户或工作空间；读取与写入分别有哪些权限 |
| 存储与部署 | 本地或自有后端、认证方式、逐字稿保留策略、应用入口 |
| 输出 | 纪要是本地文件还是本人云文档；可自动做什么、什么需要确认 |

运行模型、时区和通知频率由使用者的环境决定，仓库不预设作者的模型与日程。

## 三个阶段

1. **读源码与看前端。** 先运行 `npm run demo`，展示日历、项目或随手记的一个代表页面。示例不代表安装已完成。保留纸感、宋体标题、朱红重点和围绕业务对象组织信息的方式，也允许用户按自己的工作习惯修改。
2. **接一场会议。** 以本人的资料与授权，验证完整逐字稿读取、同场去重、确认行动、真实产物与回读。接入 `docs/ADAPTER.md` 中这一小段所需的接口。
3. **再扩展。** 有稳定证据后接系列会议、项目目录、随手记和可选留白。后台任务、跨设备与多人隔离各自有独立验收，不能自动算作第一阶段已完成。

## 适配选择

- 已有自己的 Agent 和数据存储：把 `shared/` 的字段对齐到现有工具；复用 `client/` 需要的 HTTP 接口。
- 只想复用工作方法：直接使用 `references/` 和 `templates/`，产物可先落到本地或已授权文档，无需启动前端。
- 宿主支持本地 MCP：适配自己的后端后，可用 `connector/huili_portable.py`。不支持 MCP 时，用同一个程序的 JSON CLI。
- 飞书是一个资料适配器示例，前端数据结构没有要求资料必须来自飞书。其他来源需要提供同等的来源、身份、时间和回读能力。

## 真实接入后要交付

接入说明、运行/停止方法、配置文件位置（不含秘密值）、已验证的账号与范围、可访问页面或产物、仍缺的能力。只有实际验证过的宿主写“已接入”。

遇到缺失能力，列明所缺条件与可继续的部分。不要凭空构造某家 Agent 的 CLI、深链或后台服务，也不要借用作者的实例。
