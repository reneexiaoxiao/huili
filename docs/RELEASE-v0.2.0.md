## 获取与接手

下载 `huili-v0.2.0.zip`，把整个目录交给自己的 Agent，先读 `SKILL.md` 与 `docs/TAKEOVER.md`。校验文件 `SHA256SUMS` 覆盖源码包与海报附件。海报沿用原有视觉，其使用范围同样须遵守相应材料的适用许可。
